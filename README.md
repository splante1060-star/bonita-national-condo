# Bonita National Vacation Rental Website

A modern, responsive vacation rental website for a private condominium located in **Bonita National Golf & Country Club** in Bonita Springs, Florida.

**Live Website:** [bonitanationalgolfcondo.com](https://bonitanationalgolfcondo.com/)

---

## About the Project

This project was designed to give prospective guests a complete and inviting look at the vacation rental experience before booking. The website brings together information about the condominium, community, amenities, golf membership, golf cart rental, and surrounding area in one easy-to-navigate place.

I designed and developed the website using React and TypeScript, creating reusable components, responsive layouts, image-focused pages, and interactive details that reflect the upscale feel of Bonita National.

The project gave me the opportunity to balance visual storytelling with practical information, creating an experience that feels polished while helping guests quickly understand the property and what is included with their stay.

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Deployment

The website is deployed with **Vercel**.

Every push to the main branch automatically triggers a new production deployment.

## Design Goals

The website was designed to reflect the relaxed, upscale atmosphere of Bonita National Golf & Country Club while remaining simple, informative, and easy to navigate.

Key design principles include:

- Large, immersive photography
- Elegant typography and visual hierarchy
- Responsive layouts
- Clear presentation of rental information
- Clean spacing and consistent styling
- Reusable components
- An intuitive experience for prospective guests
